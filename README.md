Esse script foi criado como forma de estudar algoritmos de decisão mais acessíveis de forma simples, seu funcionamento e aplicação em situações do cotidiano!

**Arquivos de Registro**
- arvore_decisao.txt:
    Saída do programa no estado atual
- biblioteca_dados.csv:
    Tabela de dados de treinamento usados

**Funções Principais**
- funcaotreinamento.py:
    Função usada para a criação do algoritmo de decisão.
- modulodecisao.py:
    Função de decisão lógica para melhor implementação.
- main.py:
    Programa principal.
