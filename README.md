Esse script foi criado como forma de estudar algoritmos de decisão mais acessíveis de forma simples, compreendendo seu funcionamento e aplicação em situações do cotidiano!


## Funções Principais
* `main.py`: Programa principal.
* `funcaotreinamento.py`: Função usada para a criação do algoritmo de decisão.
* `modulodecisao.py`: Função de decisão lógica para melhor implementação.

## Arquivos de Registro e Dados
* `biblioteca_dados.csv`: Tabela de dados de treinamento usados.
* `arvore_decisao.txt`: Saída do programa no estado atual.
